# Neuroscience Networks

This repository is for building and analyzing example neural networks and
studying how their components shape their behavior. The goal is to use these
examples to develop hypotheses about how neural systems work.

## Status

The repository includes editor and tooling configuration. It doesn't yet include
a runnable network example, an analysis notebook, or a Python package.

## Set Up the Editor

To use the included workspace settings, open the repository folder in VS Code
and install the [recommended extensions](.vscode/extensions.json). The workspace
uses Ruff to format Python and Oxfmt to format Markdown and TOML.
